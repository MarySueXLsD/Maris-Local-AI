## New

- **Pictures and videos right in the chat.** Next to the globe in the message box, pick **Image** or **Video**, describe what you want and press Enter. Choose the model (or let Maris pick), the shape, how many pictures or how long the clip, and see about how long it takes on your PC. Attach a picture in Video mode to animate it. Studio is gone: everything it did lives in the chat and in Models.
- **Models with much more to tell.** Models now has **Text**, **Pictures** and **Videos** tabs. Every model says who made it, how big it is, what it is good and less good at, how to write prompts for it, what your graphics card needs, how long it takes here, its files and its licence. Picture and video models show examples made with that very model; click one to see it full size, or **Use this prompt**. Language models show what they say about themselves: size, memory span, how they are stored and their licence.
- **See how full a chat is.** A ring next to the send button shows how much of the chat the model can still keep in mind. Click it to see what fills it, and summarise older messages with one click.
- **New answers get a dot.** A chat that finished while you were elsewhere is marked in the sidebar, on its folded project, and on the Chat or Code switch.
- **Paths you can click.** A folder or file Maris names in an answer opens in Explorer.
- **Code mode, smoother.** **New project** makes a folder for a new project. The file list updates by itself and shows a coloured icon for each kind of file. Open a file to read it with line numbers; select lines and **Mention lines** adds exactly that part to your message (or **Mention file** the whole file). **Changes** shows every file added, changed or deleted, in colour, with what changed line by line.
- **Maris keeps going.** There is no longer a 20-step limit: Maris works until the task is done. When a step keeps failing, it is told to try another way, and a stronger model takes over when one can run. "Continue" carries on in the same way.
- **Many files at once.** Maris can create a whole set of files or a folder tree in one step, which you approve once.
- **Answers stay in your language,** even when the files or web pages Maris reads are in another one.
- **Maris in your terminal.** Type `maris` in Terminal, PowerShell or Command Prompt to chat, `maris code .` to work on a folder, or pipe text in: `git diff | maris "write a commit message"`. It uses the same models, memory and approvals as the app, and asks before changes with a single key.
- **A better installer.** Choose a desktop shortcut, the `maris` command, "Open in Maris" in the right-click menu of folders, and starting Maris in the background when you sign in. While it copies files it says what it is doing, and its buttons are evenly spaced.
- **Projects in Code mode.** Your projects sit in the sidebar with their tasks underneath. Rename a project and tell Maris what it is about; every task in it reads that.
- **Simple view for everyone.** In Code mode, Simple view now reads like a thought you can open, in plain words, without commands or code.
- **Pictures and videos you can follow.** The chat shows which model is working, how far along it is, about how long is left, a Stop button, and a quick switch to a faster or more detailed model.
- **Installs show their size.** Before Maris installs a tool, the approval says how much it downloads and how much disk space it needs.
- **Updates & news.** Maris tells you when a new version is ready and installs it when you press **Install now**. The same page shows news and tips.
- **Skills.** Teach Maris new kinds of tasks by installing skills from a git address or a folder.
- **Connectors.** Link Maris to GitHub, Notion, Hugging Face, Brave Search, Home Assistant, Context7, DeepWiki, Stripe or any other MCP service. Anything that would change something in a service waits for your approval.

## Fixed

- Installing skills from a git address (such as Anthropic's example skills) no longer fails with "EPERM, Permission denied".
- The GitHub connector explains what is wrong with a token instead of "SSE error: Non-200 status code (400)", and a token pasted with extra spaces or "Bearer" in front now works.
- A small model no longer answers in Chinese after reading files with Japanese names.
- Deleting a chat that is still making a picture or video asks first and stops it, so nothing is made for a chat that is gone.
- "Another chat is busy" notices link to the chat that is making the picture or video.
- Every button, tab and link shows the hand pointer.
- Connectors you already added no longer appear in the list of services to add (your own servers still do).
- The picture engine starts and stops by itself; there is no engine switch to look after.
- While a picture is being made, other chats no longer just say "PC is busy": they wait a moment if it is nearly done, or answer on the processor and say so.
- While the model works between steps, Maris shows that it is still working, with a timer.
- When the model's process crashes in the middle of an answer, Maris starts that step again instead of stopping with an error.
