## New

- **Choose how much a chat keeps in mind.** Click the ring next to the send button and pick the **window size**: 8K, 16K, 32K, 64K or more. Each size says how much it holds and what it costs on your computer, for example "fits in video memory: full speed" or "about 2 GB runs from system memory: about 2× slower". Chats now start with 32K instead of 16K, and Code mode no longer shrinks it on its own.
- **More room to work.** Connected services (GitHub, Notion, …) only bring their tools when a chat needs them, so a new chat starts with about 5K tokens used instead of 20K.
- **See what Maris is doing.** Instead of "getting ready", the answer says *Loading Qwen3.5 9B into memory (6.1 GB)…*, *Reading 5K tokens…*, what the model is thinking about, or *Deciding on the next action…*, with a timer.
- **Full control of your PC, when you want it.** Settings → PC access → **Full control** lets Maris run things as administrator and use the mouse and keyboard in other programs. Every action still waits for your approval. When a task needs it, Maris shows a **Turn on full control** button in the chat.
- **Change settings by asking.** "Switch to dark mode", "make the text bigger": Maris looks the setting up and asks every time, even when other changes are approved automatically.
- **Chats as wide as your screen.** The chat grows with the window, so wide and ultrawide screens are used; **Full** uses all of it.
- **Clearer downloads.** A release has 10 files with names that say who they are for (Windows, macOS Apple silicon or Intel, Linux Debian/Ubuntu, Fedora/openSUSE or any distribution, Android) and one checksum list. On Linux, one command installs the right package: `curl -fsSL https://github.com/MarySueXLsD/Maris-Local-AI/releases/latest/download/install-maris-linux.sh | bash`. Copies installed from a .deb or .rpm update themselves with the same kind of package.

## Fixed

- Maris knows it runs on Windows 11 (it used to read its version as Windows 10) and that its commands run in PowerShell, so it runs them itself instead of telling you what to type or asking "shall I run it?".
- Tasks on your PC (finding files, checking the system) use at least the Balanced model, and "find the biggest files" is one quick look instead of a command.
- Tool names a model makes up ("sh", "system_information") are matched to the real tool instead of failing.
- A chat no longer gets summarised after a few messages and loses what you asked.
- Commands that need administrator rights are recognised before they run, so Maris asks for full control instead of claiming it did something it could not.
- When the model's process stops (for example when the graphics card runs out of memory), Maris carries on with a smaller model or on the processor instead of giving up.
- Paths with spaces in answers (`H:\Unreal Projects`) open in Explorer too.
- Dropdown lists follow the colour theme instead of showing a light list with a blue highlight.
- The setup scan on Linux names the drives ("System: 295 GB free") instead of showing "/ 295 GB".
- With "Run Maris" ticked, the installer closes first and then starts Maris, instead of hanging on screen.
