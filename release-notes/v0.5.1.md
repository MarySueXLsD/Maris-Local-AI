## New

- **Your phone, from anywhere.** Settings → Phone → **Connect from anywhere**: the phone app reaches Maris on mobile data or on another Wi-Fi through a relay that both connect out to, so nothing has to be opened on your router. At home the phone still connects directly and switches by itself. Everything stays end-to-end encrypted with the key from pairing: the relay passes messages on and cannot read them. For now it needs a relay address under **Relay address**; `relay/README.md` in the source explains how to run one.
- **Ctrl+K goes anywhere.** Type the name of a chat, a setting, a help topic, words from an old message or what you want to do (a new chat, exporting this one), then press Enter. A setting opens Settings already searched for it. On a Mac it is ⌘K.
- **Undo changes.** Under an answer that changed files, **Undo changes** puts them back: edited files return to the backup Maris made, new files and copies go to the Recycle Bin or Trash, moved things move back. You see the list first, the versions it replaces are backed up too, and Maris is told, so later answers know. Commands it ran and actions in other programs are listed but cannot be undone this way.
- **Branch from here.** A new chat with the messages up to an answer, to try another direction while the original stays as it is.
- **Export a chat.** A chat's **…** menu → **Export**: Markdown to read or share, or JSON with everything. The phone app has **Copy as Markdown**.
- **Deny and say why.** In an approval box, write what Maris should do instead ("put it in the notes folder") and it goes on from there. When Maris planned several changes at once, the ones after a denied change are not run.
- **More of a long chat on the graphics card.** Settings → Engine → **Context window memory**: *Compact*, the new default, keeps what the model is reading in half the video memory with practically the same answers; *Smallest* takes a quarter. **Flash attention** is on as well. Both apply when Maris starts Ollama itself.

## Faster

- Follow-up messages are read faster. The results of Maris's actions go back to the model exactly as it saw them the first time, so Ollama and API services reuse what they already read instead of reading the chat again. Results are only shortened when a chat no longer fits.
- Several files read in one step are read at the same time.
- Maris no longer reloads a model just to change its context window when the loaded one already fits the chat.
- Long chats scroll and type faster: messages out of sight are drawn when you scroll to them.
- With the window hidden or minimised and nothing running, the status readings are taken every 15 seconds instead of every two, so laptops can let the big graphics chip sleep.
- Saving messages and writing the log take less time.

## Safer

- **The phone app** can no longer change the phone link itself, the Ollama and ComfyUI addresses, where data is stored or where updates come from. Without **Approve changes from the phone** it can switch automatic approval, full control and connectors off, but not on, and it cannot undo changes.
- **Imported settings** cannot switch on automatic approval, full control or the phone link, or change the engine addresses or the update source; those keep their current values.
- **Web pages** Maris reads cannot lead it to addresses on your own network (the router, other computers, local servers), unless you gave it such an address yourself.
- **Instructions saved to memory** ("always answer in French") wait for your approval, since they change how Maris behaves in every chat. Memory shows which entries Maris saved itself.
- **Clipboard and screenshots**: when a chat runs on an API model, reading the clipboard or taking a screenshot asks first, since what it reads is sent to that service.
- **Updates** are installed only when their checksums can be checked, and Maris is ready for signed releases: once releases are signed, an update without a valid signature is refused.
- **The Android app** keeps its pairing keys out of Android's backups.

## Fixed

- Pictures and text files you attach are kept with the chat: they show again when you open it later, and the model can still look at them in later messages.
- Two backups of files with the same name made in the same second no longer overwrite each other.
