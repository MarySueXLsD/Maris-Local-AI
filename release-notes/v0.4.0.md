## New

- **Claude, GPT, Gemini and other models with your own API key.** **Models → API**: pick a service (Claude, OpenAI, Google Gemini, OpenRouter, Groq, Mistral, DeepSeek, xAI), paste your key, and its models appear in the model menu of every chat. LM Studio, a llama.cpp server or any OpenAI-compatible address works too. Tools, Code mode, memory and approvals work the same with them. Maris reads each service's model list from the service, so new models show up without an update, and it learns what a model cannot do (tools, pictures, thinking, a refused setting) from the service's own replies.
- **You always see where a chat goes.** An API model answers only when you pick it for a chat or give it a role (or when no model is installed on this computer at all). A cloud marks those chats and the line under the message box says where a message will be sent. Keys are stored encrypted with the system keychain.
- **Slow and old computers.** The setup assistant measures the processor and, without a usable graphics card, picks one small model for every role (Qwen3 0.6B on 4 GB of memory, Phi-4 mini on 8 GB). **Low-power mode** turns on by itself there: short instructions, only the tools a request needs (about a quarter of the usual prompt), no background model calls and a plain window. Settings → Engine → Low-power mode.
- **Tools for models without tool calling.** Very small and older models get Maris's tools described in text and can use them; nothing to set up.
- **Closing the window closes Maris completely.** Answers are stopped, models are unloaded and the Ollama server is stopped, so no video memory stays in use. If an answer, a picture, a video or a download is still going, Maris asks first. Settings → Window and startup → **Keep running in the tray when closed** keeps the old behaviour (and frees video memory a minute after the window closes); Settings → Engine → **Stop Ollama when Maris closes** leaves the server running for other programs.
- **What API models cost.** Under each answer from an API model Maris shows what it came to (for example $0.012); Models → API adds it up for today, this month and in all, per model; each model shows its price per million tokens, also in the model menu. The token counts are the services' own. Prices come from the service where it lists them, otherwise from a public list of the makers' prices looked up once a day (Settings → Engine turns that off), or from you: click a price to set your own. Settings → Engine → **Monthly guide for API costs** makes Maris say so in the chat when the month passes 80% and 100% of an amount; it never stops answering. The `maris` terminal command shows the cost of an answer and, in `maris status`, the month's total. The costs are an estimate, the service's bill is what counts.
- **Think on and off, exactly.** Newer Claude models think by themselves. **Think: off** turns that off where the model allows it, and where it does not, the thinking is shown instead of running unseen; **Think: on** asks for more effort where the model has that setting.
- **Context windows up to millions of tokens.** The context ring and Settings → Auto model choice → Context windows now go up to 2M tokens (1M for most models that offer it). For API models the size is a budget for how much of a long chat is sent with each message; a model never gets more than it takes. For models on your computer the ring says what a size costs in memory and speed, and greys out sizes the computer cannot hold. If a service says a chat is too long, Maris sends a shorter request and remembers the model's real size instead of showing an error.
- **Help**: new pages on API models, slow computers and closing Maris.

## Changed

- The default for closing the window is now "close Maris" instead of "keep running in the tray". If you had the old setting, it is switched once; turn it back on in Settings → Window and startup.
- Maris starts the Ollama server by itself, without a window or a tray icon of Ollama's own app.
- The model's instructions no longer change with every message (the time, memories and project state travel with your message instead), so follow-up messages are read faster.

## Fixed

- Without a graphics card, an answer could give up after a few minutes while the model was still reading a long prompt.
- On computers without GPU counters the status bar restarted a system tool twice a second.
- Maris's own work on the processor counted as "other programs are busy" and pushed chats to a smaller model.
- Projects on exFAT and other drives without file owners said "not a git repository".
- The same project could appear twice when its path was spelled differently.
- A chat whose first answer was stopped stayed "New chat".
- Folders named `build`, `bin` or `packages` were hidden from searches even when they held source code.
- Undo in Code mode could be made to copy any file; it only restores Maris's own backups now, also from the phone.
- The window was grey behind the content on Windows 10.
- Editing a message that asked for a picture or video sent it as a normal chat message.
- Token counts for Russian, Chinese, Japanese and other non-Latin text were far too low.
- Removing a project could leave its dialog stuck when something failed, and a failed Undo said nothing.
- Picture generation is no longer offered by default on computers without a graphics card and with less than 8 GB of memory.
